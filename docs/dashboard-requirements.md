# Dashboard Requirements

## Required Dashboard Statistics

### 1. Sales Statistics
- Total number of orders
- Total sales/revenue

### 2. Average Order Value (AOV)
- Average value of orders

### 3. Low Stock Statistics
- Low-stock ingredients/items

### 4. Active Orders
- Number of active orders
- Active orders by current status

### 5. Billing Summary
- Total billing/revenue
- Billing statistics by payment status
